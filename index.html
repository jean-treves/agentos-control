Human approval for autonomous coding agents.

AgentOS Control brings pending approvals, run status, host health, activity, diffs, and guarded controls into one place, so people can supervise work without keeping the web cockpit open.

Observe

See runs, tasks, host health, agent dialogue, activity, diffs, commits, and journal events from the local AgentOS host.

Approve deliberately

Review pending actions in a macOS notification and require local device-owner authentication before approval.

Keep policy authoritative

AgentOS remains responsible for classification, policy enforcement, and execution. The app is a control and observation surface.
